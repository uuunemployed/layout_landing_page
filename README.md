# My Bike: Landing Page

A responsive landing page for a fictional electric bike brand. It presents the bike lineup, key product details and a contact form. The project was built to practice semantic HTML, BEM methodology and SCSS by following a design mockup.

## Live Preview

[View the deployed version](https://uuunemployed.github.io/layout_landing-page/)

## Design Reference

[Figma mockup](https://www.figma.com/design/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=41317-189&t=MRte5Y2W6kJWUbiu-0)

## Technologies Used

- HTML5 (semantic markup, BEM)
- SCSS
- [Parcel](https://parceljs.org/) for bundling
- Poppins font (400, 700, 800), self-hosted with `preload` and `font-display: swap`

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/layout_landing_page.git
   cd layout_landing_page
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

3. Run the project locally:

   ```bash
   npm start
   # or
   yarn start
   ```

## Features

- Responsive layout for mobile, tablet and desktop
- Burger menu implemented with pure CSS (`:target`)
- Bike comparison section with three models
- "The Details" section with an adaptive image grid
- Contact form with required field validation
- Smooth scrolling between sections
